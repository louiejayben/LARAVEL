# Personal Task Manager

A simple Personal Task Manager built with Laravel. This project demonstrates the basic Laravel flow of Routes → Controller → Model → Database → Blade.

* **Database Used:** SQLite

 Features

* Add Task
* View Tasks
* Edit Task
* Delete Task
* Update Status (Pending/Completed)

Technologies Used

* Laravel
* PHP
* SQLite
* Blade
* HTML/CSS

 Description

The Personal Task Manager allows users to create, view, edit, delete, and update the status of their tasks. Each task contains a task name, description, status, and due date.
